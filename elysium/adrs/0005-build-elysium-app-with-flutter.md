# 0005. Build Elysium App with Flutter

![](https://img.shields.io/badge/author-romain.vasseur-ef8d22)

Date: 2026-05-06

## Status

Accepted

## Decision Outcome

Ship the mobile experience, Elysium App, with Flutter for iOS and Android.

## Context

Two native apps would double the effort for a small team.

## Decision Drivers

- One codebase
- Smooth animations
- Fast iteration

## Considered Options

### Option A: Native apps
Best fidelity, double cost.

### Option B: Flutter (chosen)
Shared code, good performance.

## Decision Rationale

The team values velocity over platform-specific polish.

## Consequences

Dart skills are scarce; some platform integrations need plugins.
