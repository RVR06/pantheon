# 0006. Use Vue for Spindle Console

![](https://img.shields.io/badge/author-romain.vasseur-ef8d22)

Date: 2026-03-10

## Status

Superseded by ADR-0007

## Decision Outcome

Build Spindle Console with Vue and TypeScript.

## Context

The team liked Vue for its approachable learning curve.

## Decision Drivers

- Developer happiness
- Quick start
- Small team

## Considered Options

### Option A: Vue (chosen at the time)
Pleasant.

### Option B: React
Common elsewhere.

## Decision Rationale

Vue fitted the small team at the beginning.

## Consequences

Converged with Olympus later; see ADR-0007.
