# 0007. Review the Spindle Console framework choice

![](https://img.shields.io/badge/author-romain.vasseur-ef8d22)

Date: 2026-09-05

## Status

Proposed

## Decision Outcome

Evaluate moving Spindle Console to React to align with Olympus Portal.

## Context

Sharing components with Olympus Portal would reduce effort; the Vue ecosystem is separate.

## Decision Drivers

- Component reuse
- Hiring
- Migration cost

## Considered Options

### Option A: Stay on Vue
No migration.

### Option B: Move to React
Align with Olympus.

## Decision Rationale

Decision pending a cost estimate.

## Consequences

Would supersede ADR-0006 if accepted.
